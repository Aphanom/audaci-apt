**Audaci** — это современный кроссплатформенный музыкальный плеер с открытым исходным кодом, написанный на Python с использованием фреймворка **Flet**. Главная особенность плеера — встроенное голосовое управление, работающее полностью оффлайн без отправки данных в интернет.

## ✨ Основные возможности

* **Голосовое управление:** Управляйте музыкой голосом (переключение треков, пауза, поиск) благодаря встроенному движку **Vosk**.
* **Умные плейлисты (Vibe DJ):** Автоматическая группировка треков по настроению (Chill, Energetic, Sad, Happy) на основе метаданных и тегов.
* **История и статистика:** Плеер отслеживает ваши предпочтения, формирует "Топ месяца" и находит "Забытые сокровища" из вашей библиотеки.
* **Кроссплатформенность:** Нативные сборки для Windows (.exe), macOS (Apple Silicon .app) и Astra Linux (.deb).
* **Безопасное локальное хранение:** Все данные, история и база треков хранятся в защищенной домашней папке пользователя (`~/.audaci/`), обеспечивая быстрый доступ и сохранность данных при обновлениях.

## 🛠 Технологический стек

* **Интерфейс:** [Flet](https://flet.dev/) (Flutter + Python)
* **Распознавание речи:** [Vosk API](https://alphacephei.com/vosk/)
* **База данных:** SQLite 3
* **Работа с аудио:** Mutagen, Python-VLC
* **Сборка:** PyInstaller (Linux/macOS), Flet CLI (Windows)

## 📦 Сборка и Релизы

В проекте настроен автоматизированный процесс сборки (Single Folder Mode), который гарантирует, что репозиторий остается легким, а сборка — быстрой.

### Локальная сборка

Для создания `.deb` пакета и одновременной синхронизации кода с GitHub используйте встроенный bash-скрипт:

```bash
chmod +x make_release.sh
./make_release.sh

```

Скрипт автоматически:

1. Активирует виртуальное окружение.
2. Подтягивает изменения из облака.
3. Собирает бинарник через PyInstaller.
4. Пакует всё в готовый `.deb` файл (папка `build_deb/`).
5. Отправляет чистый код на GitHub.

### Облачная сборка (Windows / macOS)

При каждом `git push` в ветку `main` автоматически запускается **GitHub Actions**, который самостоятельно скачивает языковую модель и собирает:

* **Windows EXE** — через нативный упаковщик `flet build`.
* **macOS APP** — под процессоры Apple Silicon (M1/M2/M3) через `PyInstaller`.

Готовые файлы можно скачать во вкладке **Actions -> [Последняя сборка] -> Artifacts**.

## 📂 Архитектура проекта

* `core/` — Логика приложения: работа с БД (`db.py`), аудиоплеер (`player.py`), парсинг тегов и обработка голоса.
* `assets/` — Графические ресурсы, иконки, плейсхолдеры для альбомов.
* `main.py` — Точка входа и UI (View/Controller).
* `audaci.spec` — Конфигурация для сборщика PyInstaller.
* `make_release.sh` — Скрипт автоматизации релизов.
