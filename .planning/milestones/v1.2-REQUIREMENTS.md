# Requirements: Milestone v1.2 (Release Infrastructure)

This milestone focuses on providing robust, out-of-the-box running application builds for macOS, Windows, and Linux via GitHub Actions (`build.yml`).

## Requirements

### Validated

- [x] **BUILD-SYS-01**: Windows standalone assembly. The executable `Audaci.exe` produced by the build pipeline contains all Python dependencies, Vosk model directory, PortAudio dynamic link libraries (`libportaudio` / `portaudio.dll` for `sounddevice`), and handles VLC engine initialization cleanly without requiring a pre-installed VLC player.
- [x] **BUILD-SYS-02**: macOS bundle portability. The generated `Audaci.app` bundle resolves all system dynamic libraries (including `PIL` dylibs, Vosk dynamic libraries, `portaudio` / `sounddevice` dylibs, and `libvlc` references). It runs cleanly on a vanilla macOS machine without missing library linkage errors (fix rpaths using `delocate` or environment configurations).
- [x] **BUILD-SYS-03**: Linux package compliance. The `.deb` package packages internal Python requirements and resource files (Vosk model, app icons), lists proper system dependencies (`libgtk-3-0`, `libvlc5`, `vlc`, `portaudio19`), and runs out-of-the-box on Debian/Ubuntu environments.
